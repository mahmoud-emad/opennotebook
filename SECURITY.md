# Security

If you've found a vulnerability, please report it privately through [GitHub's security advisories](https://github.com/mahmoud-emad/opennotebook/security/advisories/new) rather than in a public issue.

Include what you found, how to reproduce it, and what you think the impact is. You'll get a reply within a few days, and we'll keep you posted while it's being fixed.

Only the latest release and `main` get security fixes.
