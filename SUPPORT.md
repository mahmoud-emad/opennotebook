# Getting help

- **How do I…? / ideas / show and tell:** [Discussions](https://github.com/mahmoud-emad/notabit/discussions).
- **Something is broken:** [open an issue](https://github.com/mahmoud-emad/notabit/issues/new/choose). Say what you did, what you expected, and what happened, and include the version and which AI provider you use.
- **A security problem:** please don't post it publicly. See [SECURITY.md](SECURITY.md).

See [first-run troubleshooting](docs/troubleshooting.md) for database passwords, port conflicts, provider setup and slow starts. The setup tour in the app tests your provider and explains common errors.

If Notabit has helped you or your team, you can [sponsor my open-source work](https://github.com/sponsors/mahmoud-emad). It's a kind gesture, never an expectation.
